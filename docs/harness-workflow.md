# Selective PCG consumer guidance

This is the opt-in executor path from [0.10 integration](migration-0.10.md), not a
replacement for a project's AGENTS.md or automatic desktop-client installation.

At task start choose local reading/search for a known local edit, with no PCG
tools or instructions registered. For structural evidence choose the matching
static workflow from the actual canonical catalog. Use a known stable target
directly; include search discovery only for ambiguity or a missing target.
Ordinary MCP clients can register the packaged `clients/efficiency_mcp.py`
entrypoint with a fixed `--profile` and optional `--discovery`; see the
[configuration example](migration-0.10.md#ordinary-mcp-clients).

The graph guide materialized by `workflow_surface` is:

> Use the known target directly. Collect required sites before editing; preserve full IDs, offsets, confidence, snapshot and limits. Expand only a concrete missing fact or source. Static completion is not compiler/test verification. Review needs an exact baseline before editing and the same scope afterward. Omit view to use the intent source policy; request full_evidence only for a concrete missing context. If reading a whole file, collect locations first to avoid duplicate source. Follow the repository checks.

Register only that task's surface. For fused collections, decode dictionary
indexes through their complete ID tables; preserve every required site and all
limits/page states. A budget stop or changed identity needs explicit recovery.
Use the original arguments and handles with the canonical server. Do not add
status, test search, review or baseline work unless independently needed.
Through the relay, repeat the original arguments with its returned cursor to
recover one native page in the same session; keep collecting while required
sites remain. A review baseline requires that same session before and after editing.

The executor must observe actual registration, insertion, outgoing requests and
compaction. Preserve all failed attempts and receipts. Byte/character reductions
do not establish a reduction in total provider-accounted task tokens. Clients
without this integration keep the [ordinary MCP guidance](harness-AGENTS.md).
