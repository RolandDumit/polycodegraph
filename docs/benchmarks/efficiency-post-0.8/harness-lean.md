# Experimental retrieval policy

For an already located local edit, read the relevant source directly. Use semantic
retrieval to resolve identities, consumers, contracts or paths between components.
An exact reliable target needs no preliminary search.

Tool-returned source counts as a read. Reread it only for a concrete gap or source
change. Retrieve missing required sites; expand optional context for a specific
question. A complete static inventory with compatibility still unverified calls
for edits and the project's compiler/tests, not deeper graph queries.

Do not automatically add status/index/baseline/review to every task. Capture a
baseline when the requested task needs a before/after working-tree review. Honor
freshness, provider limits and untrusted-source provenance. Use targeted textual
search for dynamic/generated behavior, serialization keys, reflection, macros,
FFI and external boundaries when relevant. Preserve the project's architecture,
security rules and test policy in every condition.
