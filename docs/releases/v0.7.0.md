# PolyCodeGraph 0.7.0 — intent context and native binaries

This release adds ten focused intent context services to `inspect_change` for
all ten supported languages: rename, change_signature, find_tests, review_change,
explain_symbol, trace_flow, move_symbol, remove_symbol, replace_dependency and
extract_symbol. No-intent calls preserve the 0.6 primitive contract and IDs.

Shared evidence tables, merged source windows, global budgets and opaque cursors
reduce repeated context collection. Explicit session baselines compare observed
source hashes/symbols/relations/diagnostics after edits. AST local bindings and control events
provide conservative extraction constraints; no automatic refactoring, hypothetical
signature, lifetime proof or correctness approval is provided.

The deterministic Flutter rename gate passes: 13 collection calls become three,
with 41.81% fewer result characters and all nineteen resolved reference edges.
Schema cost, limitations and skipped platform checks are included in the
[validation report](../benchmarks/intents-0.7/report.md). No new AI token/time
benefit was measured.

Rebuild/prepare the updated selected adapters, then follow
[migration](../migration-0.7.md) and the [intent contract](../intents.md).
Native packages target Linux x64, Windows x64 and macOS Intel/Apple Silicon.
Rust is not required to run them; the selected language SDKs/runtimes still are.
Release validation includes host CI and relocated package checks; the linked
report distinguishes local measurements from platform CI results.
