# PolyCodeGraph v0.5.0 — Rust core and incremental graph queries

Rust-native CLI/MCP with SQLite persistence, reusable in-memory graph, filesystem watcher and periodic hash reconciliation. All ten semantic providers and Flutter discovery remain supported; Dart now runs as an independent Analyzer provider.

Adds inspect_change, status freshness/metrics, provider setup from the native CLI and host package workflows. Source/configuration/MCP query compatibility is retained; update the launch command from Dart to the native executable. Legacy JSON caches rebuild into SQLite and remain untouched.

Read README, docs/migration-0.5.md and VALIDATION.md before upgrading. Static/dynamic/cross-language coverage limits remain. Native packages still need selected provider runtimes and prepared dependencies. Performance evidence belongs in docs/benchmarks; no token-savings guarantee is claimed.
