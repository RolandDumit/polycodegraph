# PolyCodeGraph v0.5.0 — Rust core and incremental graph queries

Rust-native CLI/MCP with SQLite persistence, reusable in-memory graph, filesystem watcher and periodic hash reconciliation. All ten semantic providers and Flutter discovery remain supported; Dart now runs as an independent Analyzer provider.

Adds inspect_change, status freshness/metrics, provider setup from the native CLI and host package workflows. Source/configuration/MCP query compatibility is retained; update the launch command from Dart to the native executable. Legacy JSON caches rebuild into SQLite and remain untouched.

Read README, docs/migration-0.5.md and VALIDATION.md before upgrading. Static/dynamic/cross-language coverage limits remain. Native packages still need selected provider runtimes and prepared dependencies. Performance evidence belongs in docs/benchmarks; no token-savings guarantee is claimed.

## Native downloads — no Rust installation needed

Download the archive for your system and extract it. Keep the executable beside its `providers/` folder.

| System | Archive |
| --- | --- |
| Linux x64 | `polycodegraph-0.5.0-linux-x64.tar.gz` |
| Windows x64 | `polycodegraph-0.5.0-windows-x64.zip` |
| macOS Intel | `polycodegraph-0.5.0-macos-x64.tar.gz` |
| macOS Apple Silicon | `polycodegraph-0.5.0-macos-arm64.tar.gz` |

Run `./polycodegraph --version` on Linux/macOS or `.\polycodegraph.exe --version` on Windows. Then use `setup --root /path/to/project --languages <languages>` and `serve --root /path/to/project` with that executable. Rust is only needed when building the source. SDKs/runtimes for selected semantic providers remain required; see README. Dart and Go worker binaries are included.

`SHA256SUMS` contains checksums for all four archives. These assets were built and tested from commit `45fa910bde4cd98c19140b2d81ae850bea06a97c`: [20/20 passing validation jobs](https://github.com/RolandDumit/polycodegraph/actions/runs/36902837013), including relocated native worker execution on all targets.
