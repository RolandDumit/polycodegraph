# PolyCodeGraph 0.9.0 — accurate review and optional lean context

Adding unchanged lines before a function could make every reference look removed
and re-added. Version 0.9 compares semantic relations at bounded, exact source
correspondences. A native TypeScript regression with Unicode/CRLF and 100 uses
retains all uses, reports one source change and exposes 202 relocated relations
without false semantic additions/removals. Uncertain mappings retain conservative
evidence; full_evidence preserves before/after positions.

- Optional strict baseline scope rejects typos/excluded files and requires explicit
  new_files for intended creations. Captured working-tree identity and session
  scope are preserved.
- Optional format: lean groups distinct sites while keeping full IDs, confidence,
  limits and source hashes. Required inventory, optional context and unexecuted
  compiler/test verification have separate completion states. Audit stays default.
- The bounded Python LeanAdapter/Observer ships in clients/efficiency_client.py.
  Integration owns its prompt boundary; it does not automatically install in Codex.
  Instrumentation separates wire payloads from client insertion; actual model input
  remains unmeasured.
- Agent initialization explains that all ten intents use the advertised
  inspect_change; hidden primitive schemas require client registration or full profile.
- Parametric comparison tooling retains failures/retries, unknown usage, immutable
  identities, protected execution readiness and append-only resume accounting.

[Activation/rollback](../migration-0.9.md) and the updated
[consumer harness](../harness-AGENTS.md) describe formats, scopes, budgets, cursor
invalidation and recovery. All existing provider versions/resolvers and primitive
contracts remain unchanged; new options are explicit.

The dated [post-0.8 deterministic evidence](../benchmarks/efficiency-post-0.8/decision.md)
and [comparison report](../benchmarks/comparison-20261006-01/report.md) remain frozen.
The candidate measured there still identifies its original binary and source
hashes, before the 0.9 version/docs/packaging changes. Local payload reductions
are not provider tokens or AI cost. The supplementary rename replay that misses
the volume target remains visible alongside the original passing evidence gate.
No new AI executions, economic comparison or holdout were run for this release.
The earlier 0.8.0-rc.1 application pilot does not measure 0.9. Economic gates
remain unmeasured for this release.
